# Before submission

1. Open `docs/Assignment2_Report.docx` and fill in your Student name and Group on the first page.
2. Open the project in IntelliJ IDEA and use JDK 17 or newer.
3. Run `kz.aitu.smarthome.app.Main` once.
4. Run `SmartHomeTest` with JUnit 5. There are 18 tests.
5. Push this repository to your GitHub account. Keep the existing Git history because the first commit contains the version without factories.
6. Submit the GitHub repository link together with the report.
7. Read `docs/defense-notes.md` before the defense.
